# Paracolor 1.10.1 — Convite para avaliação no Google

- Adicionado em Configurações o campo para cadastrar o link de avaliação da loja no Google.
- Clientes com pedido concluído veem, em Minha conta, um convite opcional para avaliar a experiência.
- O botão abre o link seguro em nova aba. Não há coleta de avaliação nem dependência de API do Google.
